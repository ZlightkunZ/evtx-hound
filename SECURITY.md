# Security Policy

## Supported Versions
Currently, only the `main` branch is actively supported with security updates.

## Reporting a Vulnerability
I take the security of this parsing tool seriously. If you discover a vulnerability (e.g., a way to achieve Arbitrary Code Execution or a Denial of Service by providing a maliciously crafted `.evtx` file), please DO NOT open a public issue.

Instead, please email me directly (or use GitHub's private vulnerability reporting feature). 

### What to include:
- A description of the vulnerability.
- A minimal reproducible `.evtx` file (zipped and password protected with `infected`).
- The Python version and OS you tested on.

I aim to acknowledge all reports within 48 hours.
